## About
This project was developed during my internship at 9H Research Foundation, where I worked on building software solutions for livestock weight estimation. 

## Overview
HerdScale is an Android application that estimates cattle weight using side-profile images and regression models.

## Features
- Image-based weight estimation
- Regression-based prediction
- Designed for ranchers and livestock tracking

## Tech Stack
- Kotlin (Android)
- Data Analysis using Excel

## Motivation
Traditional livestock weighing is time-consuming and requires physical equipment. This app provides a faster, non-invasive alternative.

## Future Work
- Improve model accuracy
- Support multiple breeds
- Real-time video-based estimation
